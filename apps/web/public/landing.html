Solve: 2x² - 5x + 3 = 0
Let's solve this quadratic equation step by step:

1. Identify a=2, b=-5, c=3
2. Use formula: x = [-b ± √(b²-4ac)] / 2a
3. x = [5 ± √(25-24)] / 4
4. x = (5 ± 1) / 4

Answers: x = 1.5 or x = 1
